# Calculator

Консольный калькулятор на C++. Вычисляет выражения с `+ - * /`, скобками и
унарным минусом. Дополнительные функции и операторы загружаются при запуске из
динамических библиотек (`*.dll`), которые лежат в папке `plugins` рядом с
`calc.exe`. Каждая библиотека добавляет одну функцию или оператор.

```
> 16 + 4 * (3 - 1)
24
> 2^4 + sin(90)
17
> max(3, 7) + cos(60)
7.5
> ln(-100)
Error: ln: argument must be > 0
```

## Возможности

- Встроенные операции: `+ - * /`, скобки, унарный минус, числа с точкой.
- Плагины: `sin`, `cos` (в градусах), `ln`, `sqrt`, `max(a, b)`, оператор `^`
  (степень, правоассоциативный).
- Приоритеты операторов: `+ -` = 10, `* /` = 20, унарный минус = 30, `^` = 40.
- Ошибки разбора и вычислений выводятся с текстом, программа продолжает работу.
- Команды в приглашении: `help` — список операций, `exit` — выход.

## Сборка и запуск

Нужны CMake 3.16 или новее и компилятор с поддержкой C++17 (MSVC или MinGW-w64).

```bat
cmake -S . -B build
cmake --build build
build\bin\Debug\calc.exe
```

После сборки в `build\bin\Debug\` лежат `calc.exe` и папка `plugins` с `.dll`.

## Тесты

```bat
build\bin\Debug\calc.exe < tests\input.txt
```

Вывод совпадает с `tests\output.txt`.

## Структура

```
src/                      исходники calc.exe
  main.cpp                консольный цикл
  Lexer.*, Parser.*       разбор выражений
  OperationRegistry.*     реестр встроенных и загруженных операций
  PluginLoader.*          загрузка плагинов из папки plugins
  DynamicLibrary.*        обёртка над LoadLibrary / FreeLibrary
  Errors.h                типы ошибок
include/calc/plugin_api.h интерфейс между calc.exe и плагинами
plugins/                  исходники плагинов, по одной dll на файл
tests/                    входные выражения и ожидаемый вывод
```
